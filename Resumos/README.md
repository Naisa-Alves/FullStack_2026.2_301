# Resumos das Aulas - Full Stack

## 📚 Aula 1: Introdução ao HTML
- Conceitos básicos de marcação de texto.
- Estrutura fundamental: `<html>`, `<head>`, `<body>`.
- Principais tags: títulos (`<h1>` a `<h6>`), parágrafos (`<p>`) e listas (`<ul>`, `<ol>`).

## 🎨 Aula 2: Estilização com CSS
- Conceitos de sintaxe CSS (seletores, propriedades e valores).
- Formas de inclusão: Inline, Interno e Externo.
- Manipulação de cores, fontes, margens (`margin`) e espaçamentos (`padding`).

## 📐 Aula 3: Layouts e Box Model
- Compreensão do modelo de caixa (Box Model: content, padding, border, margin).
- Alinhamento de elementos com Flexbox (`display: flex`).
- Construção de estruturas de página simples.

## 🚀 Aula 4: Formulários e Avançado
- Criação de formulários (`<form>`, `<input>`, `<button>`, `<label>`).
- Tipos de entradas (texto, senha, e-mail, envio).
- Boas práticas de acessibilidade e organização de projeto.
